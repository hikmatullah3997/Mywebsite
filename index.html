GKB / Pakwan: Restaurant Management System

A ~13,200-line Java + JavaFX desktop app built solo for a multi-branch catering business. Manages day-to-day operations across three sales channels (GKB Pakwan, Kebabish Marki, Outer Pakwan), plus a per-person Khata credit ledger, expenses, and sales reporting. Java JavaFX 25 · FXML · CSS MVC · Page Cache ZXing · QR / Barcode CSV Persistence
